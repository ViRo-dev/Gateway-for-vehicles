# Gateway-for-vehicles
Защищенный шлюз для транспортных средств — это компактное embedded-устройство со встроенной операционной системой, которое устанавливается в различные транспортные средства. Шлюз собирает данные с датчиков автомобиля (по шине CAN) и передает их в телематическую систему (на облачный сервер). Реализация функциональности раннего оповещения.

Контекст
Наш продукт - защищенный шлюз для транспортных средств. Шлюз собирает данные с датчиков автомобиля (по шине CAN) и передает их в телематическую систему (на облачный сервер). Водители жалуются, что узнают о перегреве двигателя слишком поздно, когда стрелка температуры уже ушла в красную зону. Необходимо реализовать функциональность раннего оповещения.

1.	Моделируем поведение системы с помощью BPMN — чтобы наглядно показать, как система взаимодействует с внешними устройствами.
2.	Описываем сценарии работы в виде вариантов использования (Use Case) — фиксируем, что и в какой последовательности должно происходить.
3.	Декомпозируем сценарии на функциональные требования (ФТ) — то есть конкретные функции, которые нужно реализовать разработчикам.
4.	Добавляем нефункциональные требования (НФТ) — ограничения по производительности, надежности, безопасности, которые критичны для встраиваемых систем.

Сценарий:
1.	Шлюз получает температуру с CAN-шины каждые 100 мс.
2.	Если температура превышает порог 95°C, шлюз отправляет предупреждение на панель приборов (выводит сообщение водителю).
3.	Водитель должен подтвердить получение предупреждения (нажать кнопку).
4.	Если водитель не подтвердил предупреждение в течение 10 секунд, или температура продолжает расти и достигает 105°C, шлюз отправляет критическое предупреждение (звуковой сигнал + мигающее сообщение) и фиксирует событие в лог.
5.	Водитель глушит двигатель или снижает нагрузку, температура падает.
